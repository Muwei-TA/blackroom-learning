# 隔离环境验收与发布阻断项

**此文件是后续验收说明，不是本次已经执行的部署记录。不要在生产站点复制执行。**

## 1. 先证明环境隔离

使用单独主机/容器和数据库，不连接生产 PostgreSQL/Redis，不使用生产 API 密钥。测试邮件、webhook、外部 AI 调用以及其他自动通知要在测试环境禁用或重定向到测试接收端。优先使用合成成员和内容，不能因为测试就复制真实私密资料。

确认生产实际 Discourse 版本和 SHA；开发参考 SHA 为 `6318da11adede54e9e5b2bbbeef8a79c2157503c`。先在固定参考版本验证，再针对真实生产版本验证差异。不要只看 `2026.10.0-latest` 字符串就视为两个构建相同。

只有经后续明确授权，才应在隔离副本中将插件放入 `plugins/blackroom-learning`。本次没有上传插件到任何服务器。

## 2. 宿主后端验证

按照该版本 Discourse 的开发文档准备 Ruby、Node、PostgreSQL、Redis、Bundler/pnpm 和测试库。在专用测试数据库中先运行迁移与请求测试。下面命令尚未在本次环境执行：

```bash
# 仅在已确认的隔离 Discourse 源码根目录中执行。
# 检查本地配置与环境变量，确保数据库/Redis 不是生产实例。
RAILS_ENV=test LOAD_PLUGINS=1 bundle exec rake db:migrate
RAILS_ENV=test LOAD_PLUGINS=1 bundle exec rspec plugins/blackroom-learning/spec/requests/learning_spec.rb
```

测试目录内 19 项请求示例覆盖身份、审核、去重、权限及回滚，但执行前仍须确认目标版本的测试辅助方法兼容。除插件测试，还须运行宿主要求的 lint/相关回归套件；依版本使用其现有前端构建和测试命令，不把单独 `npm test` 当作 Discourse 构建。

必须另外执行真正多连接并发测试：同一 UUID 重发、不同 UUID 同日发帖、发帖与回补并行、两个建目标请求并行、进程在提交中断后重试。断言话题/回执数量、每日一条有效结果、XP合计与流水版本唯一性。不能用单线程重复调用代替并发证据。

## 3. 测试站配置与成员验收

在测试站建立专用学习分区与公共 Flag 话题，先核对分区访问权限。运营机器人发测试说明帖时仍只使用 discobot；管理员不代发社区内容。也可以在隔离环境使用明确标注的测试用户手工创建测试夹具。

设置 `blackroom_learning_category_id` 和 `blackroom_learning_flag_topic_id`，最后仅在测试站开启 `blackroom_learning_enabled`。原生徽章 ID 全部保持 0，先验证核心功能。不要在有进行中目标时重新指向另一个分区/Flag；历史查询范围也会受配置影响，第一版没有迁移工具。

成员端完整验收路径：打开 Flag → 填表 → 审核/发布 → `/learning` 目标卡 → 发布关联学习话题 → 进度增加 → 同日再次发帖不增加天数 → 删除/恢复按规则重算。验证北京时间 23:59 与 00:01、月底/闰年、截止日晚提交翌日批准、Flag 先待审核、目标主动结束、网络超时重试。

前端专门验证：GJS 构建无错误；Flag 面板普通视图与嵌套视图；进入/退出话题时插槽生命周期；个人主页入口；手机表单输入/软键盘；所有错误提示；非公开目标不出现在他人数据中。当前开发版是 Markdown 文本输入，没有原生图片上传选择器；未通过原生编辑器接入验收前不要宣传支持拖拽上传。

## 4. 私密权限与徽章

用至少两个不同权限测试成员验证分区和帖子隐藏前后 JSON 响应，检查不仅没有标题/正文泄漏，也没有通过天数/XP/成就泄漏。徽章属于原生资料体系，可能有更广可见性；桥接默认关闭，私密学习分区不得启用。

启用桥接前建立四个专用手动非头衔徽章；验证重复授予、既有他人授予徽章、手动撤销、记录失效、分区改为私密、学习功能关闭等情形。徽章撤销是事件/回补异步过程，不能把“最终会撤销”当作即时访问控制。计划调整分区权限或关闭功能前，先在测试验证并处理已有学习徽章；第一版不提供一键清理/权限迁移。

## 5. 回滚与最终放行

本包不含发布或自动回滚脚本。功能开关关闭会停止学习接口和重算，但不会删除已发的 Flag/学习话题，也不会自动清理已经授予的原生徽章。保留插件业务表和流水，不在未备份情况下反向迁移或删除数据。

未来生产变更须另行授权，并具有备份、回滚演练、固定版本、后端/前端/权限验收记录。当前状态只允许继续审查和隔离测试，不允许据本报告直接上线。
