# BlackRoom Learning · 0.1.0-dev

**状态：开发版源码，待 Discourse 集成验证。不是已安装的功能，也不是生产就绪版本。**

本插件把公开 Flag、成员自己的学习话题、按天去重的进度与学习奖励连接起来。所有功能默认关闭。本仓库仅托管开发版源码，不包含自动部署流程；没有创建线上分区/话题，没有修改线上配置，没有部署。

## 已写入的功能

- Flag 话题面板与结构化目标表单：名称、每日约定、开始日期、截止日期和需要完成的学习天数。提交后以当前登录成员的身份，经正常审核管线创建 Flag 回复，并附带目标进度链接。
- `/learning` 目标广场：自己的近期目标、按成员/目标筛选、分页浏览、目标进度卡、学习日历及最近 50 篇记录。Flag 面板显示最近四个可见目标；旧回复可通过进度链接查看，不给每一层回复单独插入卡片。
- 关联话题打卡：通过学习表单提交正常话题。内部 receipt 绑定目标和帖子/审核记录；不根据标题、标签、AI 猜测归属。普通编辑器直接发出的无关联帖子不自动计入。
- 有效自然日去重：固定北京时间 Asia/Shanghai，真实打卡日期数 ÷ 目标天数；百分比最高 100%。审核通过后归入服务器记录的原始提交日期。
- 每位成员每日首次有效打卡 10 XP，等级从 1 开始，每 100 XP 升一级。真实连续记录、最长连续记录，以及首次打卡/连续 7 天/累计 30 天/目标完成四类站内学习成就。
- 可选原生徽章桥接：默认全部 ID 为 0，不自动创建徽章；只支持专用、手动、非头衔徽章，限制私密分区信息外溢。学习成就展示不依赖桥接。
- 同日重复发帖不重复计天；删除、隐藏、恢复及移出分区可触发重算。奖励以追加正负流水实现撤销和恢复，保留历史，不把编辑旧帖当新打卡。
- 默认拒绝机器人、匿名和 staged 账号。登录、目标所有权、分区/话题/帖子可见性、普通审核、限流、请求去重和用户级事务锁均在服务端实现。

## 规则与当前范围

目标为 1–366 个真实学习日，包含首尾两天的总计划区间不超过 366 天；可以在 40 个自然日里完成 30 个学习日。每位成员只能有一个进行中、预定或待审核目标。目标提交后不能修改日期/分母；可主动结束，保留历史成果。截止未完成会展示已结束，不清空累计天数。首次达标后封存目标；之后删帖会降低进度/撤销奖励，但不会把已完成目标重新激活，与新目标形成两个进行中目标。原记录恢复仍可恢复进度。

进度只代表执行学习记录约定，不代表真正掌握知识。审核/恢复后可能补入原始提交日期；存在多个已提前提交的待审核记录时，真实天数可以超过目标天数，但百分比仍封顶 100%，每日 XP 仍按用户和日期去重。

第一版不含冻结卡、学习币、商城、周榜、提醒、组队、多目标、旧帖回填及旧分区迁移。暂不接入原生富文本编辑器与上传选择器；打卡表单使用 Markdown 文本输入。页面在提交和主动刷新时更新，没有实时推送订阅。个人主页添加受权限控制的学习页面入口，而不是直接公开聚合数据。
